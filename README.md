
Family Meds Tracker

Family Meds Tracker is a long-term care application designed to track family medications, monitor low-stock levels, and send proactive restock alerts. It helps caregivers and families manage recurring prescriptions seamlessly, ensuring no one ever misses a critical dose due to an empty bottle.

🚀 Features
• Long-Term Medication Tracking: Log and monitor prescriptions, dosages, and schedules for multiple family members.
• Inventory Management: Real-time tracking of remaining pill/liquid counts.
• Low-Stock Alerts: Automated notifications when a medication falls below a customizable threshold.
• Caregiver Dashboard: A centralized view of all family members and their current adherence statuses.

🛠️ Tech Stack
• Frontend: React / React Native (or your choice)
• Backend: Node.js / Express (or your choice)
• Database: MongoDB / PostgreSQL (or your choice)
• Notifications: Twilio SMS / Firebase Cloud Messaging (or your choice)

📋 Usage Guide
1. Add Family Members: Create profiles for each dependent.
2. Input Medications: Enter the name, dosage frequency, and initial stock count.
3. Set Thresholds: Define the "low stock" limit (e.g., alert me when only 5 days of medication remain).
4. Receive Alerts: Get notified via [SMS/Email/Push] the moment stock runs low.
